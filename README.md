## Project Description

Word Sense Disambiguation (WSD) is the NLP task of automatically determining which meaning of an ambiguous word is intended in a given context. This project implements multiple WSD algorithms and evaluates them on a biomedical dataset, with a particular focus on medical and clinical text.

### What is implemented

| Task | Description | File | Status |
|------|-------------|------|--------|
| 1 | Basic Lesk algorithm (NLTK) on example sentence | `wsd.py` | Complete |
| 2 | NLTK Lesk evaluation on MSH-WSD sample (10 regular + 10 acronyms) | `evaluation.py` | Complete |
| 3 | Compare 8 WSD algorithms (pywsd) | `wsd.py` | Complete |
| 4 | Full dataset evaluation of all algorithms | `evaluation.py` | Complete |
| 5 | Phonetic similarity (fuzzy NYSIIS + edit distance), distance matrix | `phonetic.py` | Complete |
| 6 | Combined Wu-Palmer + phonetic WSD (α = 0.5) | `wsd.py`, `evaluation.py` | Complete |
| 7 | Streamlit GUI | `app.py` | Complete |
| 8 | Literature review | `docs/literature_review.md` | Complete |

## Dataset

The evaluation uses a curated biomedical WSD dataset based on the **MSH-WSD** (Medical Subject Headings Word Sense Disambiguation) terminology from Stevenson et al. (2010).

**Dataset statistics:**
- 27 ambiguous terms (17 regular terms, 10 acronyms)
- 259 annotated instances
- UMLS CUI sense labels

**Note on sense mapping:** MSH-WSD sense labels are UMLS CUIs, not WordNet synset IDs. The evaluation uses word-overlap between predicted WordNet definitions and UMLS sense labels as an approximation. Coverage (fraction of instances where the target word has WordNet entries) is reported separately from accuracy.

---

## Algorithms Implemented

### Lesk Variants (pywsd)
- **Original Lesk**: Uses definition overlap only
- **Adapted Lesk**: Uses definition + related synsets
- **Extended Lesk (hyperhypo)**: Includes hypernyms and hyponyms
- **Cosine Lesk**: TF-IDF cosine similarity on synset signatures

### Similarity-Based (pywsd)
- **Path Similarity**: Graph distance in WordNet taxonomy
- **Information Content (Resnik)**: Corpus-based IC of least common subsumer
- **Wu-Palmer**: Depth-normalized path similarity
- **Highest Lemma Count**: Most frequent sense baseline

### Combined Method
- **Wu-Palmer + Phonetic (α=0.5)**: Convex combination of semantic and phonetic similarity

---

## Known Limitations

1. **UMLS–WordNet mapping**: The evaluation is approximate. True accuracy on the MSH-WSD benchmark requires an exact UMLS CUI → WordNet synset mapping, which is not publicly available. This project uses definition-word overlap as a proxy.

2. **Acronym coverage**: Many biomedical acronyms (e.g., "MS", "BP", "PE") are absent from WordNet. Evaluable coverage for acronyms is lower than for regular terms.

3. **fuzzy.Soundex**: The Soundex function in the `fuzzy` library produces non-printable output on Python 3.9 + macOS. The project uses `fuzzy.nysiis()` (NYSIIS) and `fuzzy.DMetaphone()` instead, which work correctly.

4. **Performance**: Similarity-based algorithms (Path, Wu-Palmer) are slow on the full dataset because they enumerate all synsets of context words.
